# USST Curriculum Exporter

将上海理工大学教务系统中的个人课表一键导出为 iCalendar（`.ics`）文件，可导入 Apple 日历、Google Calendar、Outlook 等日历应用。

## 功能

- 自动解析课程名称、星期、节次、教学周、地点、教师、考核方式与学分。
- 支持连续周、离散周、单周和双周。
- 使用 `Asia/Shanghai` 时区。
- 可选择不开启提醒，或提前 10、15、30 分钟提醒。
- 导出前要求确认“第 1 周周一”，避免不同学期的日期偏移。
- 生成标准 iCalendar 文件，无需上传课表或账号信息。

## 安装

需要先安装 [Tampermonkey](https://www.tampermonkey.net/) 或 [Violentmonkey](https://violentmonkey.github.io/)。

安装扩展后，可以采用以下任一方式：

1. 打开仓库中的 [`usst-timetable-export.user.js`](./usst-timetable-export.user.js)，点击 GitHub 的 **Raw** 按钮，脚本管理器会提示安装。
2. 在脚本管理器中选择“新建脚本”，复制 `usst-timetable-export.user.js` 的全部内容并保存。

## 使用

1. 登录上海理工大学教务管理系统。
2. 进入 **信息查询 → 个人课表查询**。
3. 选择学年、学期，点击“查询”，并保持在“表格”视图。
4. 点击“输出PDF”旁新增的 **导出 ICS** 按钮。
5. 核对“第 1 周周一”的日期，并选择提醒时间。
6. 点击“导出 .ics”，再将文件导入你的日历应用。

脚本仅匹配以下页面：

```text
https://jwgl.usst.edu.cn/jwglxt/kbcx/xskbcx_cxXskbcxIndex.html*
```

## 注意事项

- 脚本只读取当前页面已经显示的课表，不会收集或上传账号、学号、课表或其他个人信息。
- 日历按照教务系统显示的教学周生成，不会自动处理临时调课、停课、节假日补课或教师临时通知。
- 首次用于新学期时，请务必根据学校校历确认“第 1 周周一”。
- 同一份课表重复导入日历可能产生重复事件，建议先删除旧日历或导入到单独的课程日历。
